# 术语表

| 术语 | 定义 |
|------|------|
| 插件 (Plugin) | 扩展 Claude Code 功能的组件集合 |
| 市场 (Marketplace) | 插件发布和分发平台 |
| 技能 (Skill) | AI 自动调用的场景化行为指南 |
| 命令 (Command) | 用户 `/` 手动触发的操作 |
| 子代理 (Agent) | 专门处理某类任务的微型 AI |
| 钩子 (Hook) | 事件驱动的自动化触发器 |
| 清单 (plugin.json) | 插件元数据和组件声明 |
| 硬关卡 (Hard Gate) | 不可跳过的流程步骤 |
| 测试先行 (TDD) | 先写失败测试→实现→重构 |
| 子代理驱动 (Subagent-Driven) | 每任务派新 agent 的实现方式 |
| 工作树 (Worktree) | Git 隔离开发环境 |
| MCP | AI 工具集成协议 |
| 规则 (Rules) | 始终生效的编码约束 |

:::info[参考来源]
术语定义来自 Claude Code 官方文档和 ECC/Superpowers 插件源文件。
:::
