# subagent-driven-development

**触发时机**：执行实现计划时。

## 机制

每个任务派发一个**全新子 agent**，上下文隔离，不继承主会话历史。

## 两轮审查

1. **Spec 合规审查**：代码是否完全匹配规格？
2. **代码质量审查**：代码质量、安全性、可维护性

每轮不通过→打回重做→再审查。

## 模型选择策略

- 机械实现（1-2 文件）→ haiku（快且便宜）
- 集成任务（多文件）→ sonnet
- 架构/审查 → sonnet/opus

## 效率优势

- 子 agent 零上下文污染
- 持续执行，任务间不暂停
- 自动检查点，失败可回溯
