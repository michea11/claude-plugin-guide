# doc-updater

> *Documentation and codemap specialist. Updates codemaps, generates architecture docs.*

文档更新 agent。同步代码变更到文档，生成架构 codemap。

## 何时派发

- `/update-docs` 命令
- `/update-codemaps` 命令
- 代码变更后

## 能力

- 同步 scripts/schemas/routes 到文档
- 生成 token-lean 架构图
- 更新 README 和指南
