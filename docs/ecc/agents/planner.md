# planner

> *Gather requirements, assess risks, and create step-by-step implementation plan.*

需求分析 agent。输入一句话需求，输出结构化实现计划。

## 何时派发

- 复杂功能需求
- 重构请求
- 需要实现规划的任何任务

## 输出

```markdown
## 实现计划

### 需求复述
### 实施阶段
### 依赖
### 风险
### 等待确认
```

## 相关命令

`/plan` 直接调用此 agent。
