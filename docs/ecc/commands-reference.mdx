### 核心链路

最常用的 4 个命令形成开发闭环：

```
/plan → /tdd → /code-review → /build-fix
```

| 命令 | 干什么 | 谁执行 |
|------|------|------|
| `/plan` | 分析需求，输出实现计划 | planner agent |
| `/tdd` | RED→GREEN→REFACTOR 强制流程 | tdd-guide agent |
| `/code-review` | 代码质量+安全+模式审查 | code-reviewer agent |
| `/build-fix` | 最小 diff 逐个修复构建错误 | build-error-resolver |

:::tip[详细用法]
核心工作流的完整说明见 [ECC 核心工作流](core-workflow) —— 含代码示例、场景策略和 admonition 提示。
:::
