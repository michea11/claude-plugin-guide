# search-first

> *Research-before-coding workflow. Search for existing tools, libraries, and patterns before writing custom code.*

先搜再写——不重复造轮子。

## 触发条件

- 开始一个可能有现成方案的新功能
- 添加依赖或集成
- 准备写新的工具函数或抽象

## 工作流

1. 搜索现有库和方案
2. 对比 2-3 个候选
3. 选择最匹配的
4. 才考虑自己写

:::tip
"不要写 100 行代码解决一个 npm 包能解决的问题。"
:::
